# Pipe Roach

Pixel-art parkour about a lonely smoker. **Pipe Roach** leaves a rocky forest, crawls the Pipe Line, and finds **Babe Roach** waiting at the grate.

## Play

After a push to `main`, GitHub Pages builds the game automatically:

**https://kylenauj.github.io/parkour-dash/**

```bash
npm install
npm run dev
```

Open `http://localhost:43173`. **Full crawl** plays all six stages. Jump into a single stretch from the title screen.

| Action | Keys |
| --- | --- |
| Move | `A` `D` or arrows |
| Jump / wall kick | `Space`, `W`, or `↑` |
| Dash | `Shift` or `J` |
| Slide / drop through | `S` or `↓` |
| Slide-dash | Hold `↓` and dash on the ground |
| Talk | `E` |
| Pause | `Esc` or `P` |
| Last valve | `R` |

Walk under hanging pipes onto a stoop. Hold into the wall and jump to kick across. Jump through the grate at the top.

## The crawl

1. **The Ridge** — leave the camp, hop the rocks, enter the Pipe Line.
2. **The Gutters** — jumps, wall-kicks, slides, a dash over the drain.
3. **The Filter** — rust, plates, presses, a stack you can walk into.
4. **The Overflow** — currents, drips, updraft, triple kick.
5. **The Flues** — stay low. Slide-dash the sooty tunnels.
6. **The Grate** — the exam. Babe Roach is at the top.

Crumbs, talking roaches, and stashes unlock looks. Unlocks save in the browser.
